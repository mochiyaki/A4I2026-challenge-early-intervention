SELECT * FROM GRAPH_TABLE(
  a4i_early_intervention.ReferralGraph
  MATCH (c:CareNode {node_role:'Screening_Pediatric_Clinic'})
        -[r:ReferralHandoff]->{2,4}
        (v:CareNode {node_role:'EI_Therapy_Vendor'})
  WHERE c.state_code = 'MS' AND r[OFFSET(0)].hop_sequence = 1
    AND (SELECT COUNT(DISTINCT h.case_chain_id) FROM UNNEST(r) AS h) = 1

      chain_wait_days = (SELECT SUM(h.handoff_wait_days) FROM UNNEST(r) AS h)
  RETURN chain_id, r[OFFSET(0)].target_provider_id AS intake_coord_id, total_hops, chain_wait_days
) QUALIFY ROW_NUMBER() OVER (PARTITION BY chain_id ORDER BY total_hops DESC) = 1;

Verified Data & Graph Rigor: 4 Subtle Evaluation Traps Defeated

Public health analytics fail silently when FIPS leading zeros drop, zero-filled columns distort formulas, or variable-length graph paths double-count sub-prefixes.

Trap 1 · Leading-Zero FIPS Preservation ('06...' & '01...')

Casting GEOIDs to INT64 silently corrupts California (06) and Alabama (01) joins. Every SQL & Python pipeline enforces 11-char LPAD(..., 11, '0') strings — verified across all 101 CA tracts ('06...', 41,144 under-5 children) and 43 AL tracts ('01...', 9,396 under-5 children).

Trap 2 · All-Zero ACS limited_english_rate Column

In the starter ACS extract, 426 / 426 tracts (including 64/64 in MS and 101/101 in CA) carry 0.0 in limited_english_rate. Our tools exclude this zeroed column from need scores and join provider bilingual_services_listed + statewide HRSA NSCH language strata instead.

Trap 3 · Statewide-Only NSCH Grain (Zero 6x Tract Fan-Out)

nsch_developmental_screening_survey has geographic_level = 'Statewide' (6 income/language strata per state · 36 rows total). Joining NSCH directly onto tracts inflates child counts 6x; we query NSCH strictly as a separate statewide context table.

Trap 4 · Correlated & Prefix-Deduplicated ISO GQL

Unconstrained -[r:ReferralHandoff]->{2,4} stitches unrelated children's hops and double-counts 3-hop prefixes of 4-hop Type B (Vendor -> Vendor) chains. Enforcing COUNT(DISTINCT h.case_chain_id) = 1 + QUALIFY ROW_NUMBER() ... ORDER BY total_hops DESC = 1 yields the exact 44 MS chains & 26 breaches.
